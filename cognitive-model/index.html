About This Model

Semantic Network

Phenomenological concepts (somatic sensations, kinetic phenomena, emotions, visual experiences, cognitive shifts, and narrative/self processes) are represented as nodes in a semantic network. Edges represent co-occurrence and temporal sequence relationships.

Spreading Activation

When a concept is activated (clicked), activation spreads through the network along weighted connections. This models how activating one aspect of experience can prime or trigger related phenomenological dimensions.

Consciousness Parameter

The slider modulates edge weights between baseline and altered-state configurations. At higher values, cross-modal connections strengthen, activation spreads more broadly, and network entropy increases — modeling reduced top-down predictive constraint.

State Classification

The model classifies the emergent network activation pattern into phenomenological state categories, showing which experiential domains are most active. This bridges computational dynamics and qualitative experience categories from the CEFE questionnaire.
